# M Template

M Template is Windows software for digital templating and stone-worktop drawing preparation.

Current version: **V1.2.8**

[Download the latest M Template installer for Windows](https://github.com/mariuszstonesystem-ux/MobileDigitalTemplate-Releases/releases/latest/download/M-Template-Setup.exe)

[Latest release, checksums and third-party component sources](https://github.com/mariuszstonesystem-ux/MobileDigitalTemplate-Releases/releases/latest)

[Download V1.2.8 directly](https://github.com/mariuszstonesystem-ux/MobileDigitalTemplate-Releases/releases/download/v1.2.8/M-Template-Setup-1.2.8.exe)

You can update directly from an earlier version. Intermediate installations are unnecessary.

Updates and reinstalls replace application files while preserving your existing libraries, settings, Jobs, History, photos, Site Jobs and other saved work. Missing or deliberately deleted library files are not added back automatically.

The updated factory libraries are applied to an existing installation only when you choose **Settings > Admin > Restore Factory Settings To Original** and confirm. Restore replaces All Styles, M Edge, M Preset Block, Quick Text and Admin settings, and clears Table and Email settings, including the address book and saved app password. Export settings you want to keep before restoring. M Jobs, M History, Site Jobs and work saved in other locations are preserved.

A first installation includes 151 factory Preset Blocks, 26 Edges (including Printed Arris and Printed Pencil), 15 drawing Styles, six text Styles and 58 Quick Text notes. Table and Email start empty.

This public repository distributes release information, the Windows installer, checksums and required third-party component sources. Application source remains in a separate private repository.
