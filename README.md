V1.2.5 corrects the factory content from V1.2.4: it includes the latest approved 151 factory Preset Blocks (102 updated files), 15 current Styles and 24 factory Edge profiles, along with all previous application and geometry improvements and the .NET desktop runtime.

This complete installer supports first installation and updates. Check For Update in V1.2.4 now offers V1.2.5. Installation and updates replace the editable settings and factory libraries with the new defaults. Saved jobs, history, photos, additional custom presets and 6 Site Jobs are kept. The saved jobs location and history retention setting are preserved. Admin Settings includes **Restore Factory Settings 1.2.5**.

The older V1.2.4 installer has been withdrawn. V1.2.5 is the currently published release.

This public repository contains installers and release information. Application source code remains in the private repository.
